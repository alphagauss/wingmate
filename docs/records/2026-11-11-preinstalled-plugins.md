# 2026-11-11 Wingmate 预装插件标签页

在 DSH `0.2.2-rc.1` 的「插件」面板通过 `plugins.tab` 添加「Wingmate 预装」。三个插件继续由 Wingmate 启动补丁加载，界面从 DSH 插件清单读取宿主状态，从实际注册的预览读取格式。桌面快捷入口打开现有后台服务设置。

执行后端卡片的状态读取与主动检查分开。主动检查复用现有 ACP 连接及会话列表，使用 DSH 只向 owner 开放的 API 路由。侧栏发现适配器不可用时提供直达标签页的入口。ACP 接入 TypeScript 时修正了 SDK 请求超时选项，初始化、会话列表、加载和创建的等待期限现在由 SDK 执行。

## Windows 验证

- `pnpm test`、`pnpm build`、`pnpm test:smoke` 通过。复制出的单文件 EXE 提供预装插件标签页，诊断状态读取无需启动 Agent，匿名访问被 DSH 拒绝。测试同时验证连接失败后可重试。
- Chrome 和 Tauri WebView2 显示三个已加载的插件与实际注册的预览格式。发行版桌面从标签页打开已有后台服务设置，普通浏览器显示预装状态。
- 在隔离宿主的 PATH 中移除 Codex 适配器目录，验证侧栏禁用 Codex、可直达诊断及安装指引。使用真实 `codex-acp` 的 Chrome 和发行版 Tauri 验证打开标签页不发起连接，主动检查成功且不切换工作台。
- 发行版后台上的 DSH 和 Codex 都完成了真实回复。发送 DSH 消息后，在任务运行期间通过侧栏切到 Codex，另一标签页留在 DSH 并读到原任务的完整回复。

更新跟随 Wingmate 运行包，现有后台在显式重启后加载新版。macOS 和 Linux 本轮未运行验收。
