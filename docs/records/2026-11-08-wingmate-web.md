# 2026-11-08 Wingmate 后台服务插件

DSH 保持 `0.2.2-rc.1`。本次将 [Wingmate 后台服务](../../plugins/wingmate-web/README.md) 作为独立包放在 DSH 旁边并默认加载，同时将发行运行目录切换为按归档指纹命名。

11 月 8 日至 9 日在 Windows x64 上检查了开发安装树的补丁合成，以及 `.tgz` 在独立 Web Profile 中的安装、加载和移除。复制出来的单文件 EXE 通过发行冒烟测试，覆盖运行包只内嵌一份、指纹复用、Web 认证、插件资源及现有原生依赖。

旧版 EXE 启动同一 DSH 版本后，新桌面仍可连接原后台。确认重启才使用含插件的新目录，原运行目录保留。测试使用独立管理目录、DSH 目录和 WebView 数据。

移除菜单后复测了设置页取消与确认、停止后回首页、启动失败后重试、重启后自动连接、拒绝过期后台实例以及关闭窗口后后台继续运行。Win32 窗口检查确认原生菜单栏已移除，普通 Chrome 中的 DSH 设置不显示桌面后台服务入口。

11 月 9 日审核后，用文件锁暂缓已确认的重启并关闭窗口，确认桌面等新后台启动后才退出。故意损坏构建归档后，准备脚本重建了相同指纹的运行包。首页渲染调整后再次通过单文件冒烟和桌面启停验证。

本次没有使用模型凭据，未验证实际模型推理，也未验证其他平台。
