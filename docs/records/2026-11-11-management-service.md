# 2026-11-11 独立管理服务与无 GUI 引导

B1 将发行引导和业务生命周期分离。`wingmate` 统一携带独立服务、运行资源及可选桌面组件，准备资源并协调版本；`wingmate-service` 使用已安装内容，不内嵌 DSH 归档。仍使用锁定的 DSH 发布包，未改变会话、凭据与用户设置的归属。旧发现协议不做迁移，升级前显式停止旧后台。

本轮在 Windows x64、系统 Node 24.15.0 运行验证：

- `pnpm test` 通过，覆盖旧有打包、插件、窗口和命令注册行为，以及独立宿主的认证、重复启动、实例绑定、停机恢复和损坏配置拒绝。命令注册使用隔离注册表测试，不修改日常用户设置。
- `pnpm build --headless` 与 `pnpm build` 通过，复用默认 Cargo 构建目录和归档缓存。无 GUI 入口的依赖图不包含 Tauri、GTK 或 WebView。开发服务从受管释放副本运行时，重复执行 `pnpm runtime:dev` 成功，服务和业务实例均未切换。复制出的无 GUI 产物在空管理目录执行 `service-start`，业务仍停止；移走外层发行入口后，经本机管理接口可反复启动与停止 DSH。
- `pnpm test:smoke` 验证单文件只携带一份各运行归档，释放后的服务没有运行归档；并发启动复用管理与业务实例。验证真实 DSH Web 登录、预装插件资源与受影响的原生模块。异常结束服务不会结束业务，重新引导可恢复同一业务实例。组件切换用修改测试副本 PE 提示文字模拟服务指纹变化，确认需要显式切换、旧组件被回收、旧入口不会自动降级服务。
- Windows 实际 WebView2 通过 CDP 验证开发版与复制出的桌面发行版。设置页确认停止后回首页，服务仍在线；首页重新启动，工作台恢复。发行双窗口共享实例，关闭全部窗口不影响后台，再次打开继续连接；窗口打开时可替换外层 EXE。测试业务与服务均已停止。

macOS、Linux 分支做静态检查，本轮没有在这两个平台运行。未进行真实模型调用、局域网配对、隧道或系统级服务注册验证；本机管理接口不代表 B2 的远程访问已交付。
