# 2026-11-11 ACP 执行后端插件

A1 采用普通 DSH 组合插件，在同一个插件中分开维护 Web 投影、通用 ACP 客户端和 Codex 命令适配。DSH 始终提供 Web、插件和原生 Agent；切换只改变当前页面的工作区、会话及操作目标。Claude 留待后续按需接入。能力范围和部署入口见[插件文档](../../plugins/wingmate-backends/README.md)。

## 来源与取舍

- DSH 保持锁定的 npm 发布版，插件网关适配不增加上游源码补丁。
- 工作区、会话和流式投影复用并调整自 ds-harness-remote 的 `7d4d73baee7b`，随包保留 MIT 许可。适配器使用现成的 `codex-acp`，Wingmate 的 ACP 客户端通过 SDK 实现，SDK 在构建时内联并携带 Apache-2.0 许可。精确构建依赖进入插件声明与 pnpm 锁文件。
- 本轮使用 `codex-acp@2.6.0` 和其随 npm 包提供的 Codex，复用主机既有登录和原生会话。已在开发机安装该版本，并验证无需测试路径覆盖即可通过 PATH 发现和实际调用。Agent 运行内容属于主机依赖，发行 EXE 携带插件与 ACP 客户端。
- 新增目录与别名只保存到插件自己的目录索引。展示事件留在宿主内存，历史恢复读取 Agent 的原生数据。

## Windows 验证

验证环境为 Windows x64、系统 Node 24.15.0。使用隔离 DSH 数据目录、专用 Codex 测试会话和独立浏览器资料目录。

- `pnpm test`、`pnpm build` 和 `pnpm test:smoke` 通过。新增自动化覆盖 ACP 历史、并发发送去重、中断、审批关联、目录索引并发写入与恢复、两种 DSH 调用载体以及外部会话的界面能力。实际归档检查宿主独立导入、页面 transport、补丁和许可文件，复制出的单文件产物提供预装客户端。
- 普通 Chromium 浏览器的两个标签页分别使用 DSH 与测试 Agent，工作区、会话和实时事件保持各自目标。匿名请求被既有 DSH 认证拒绝。切换使用完整工作台，设置和原生模块继续使用 DSH。
- 已登录 DSH 真实发送后切到 Codex，再读取 DSH 原生历史，任务正常完成。
- Codex 在原有 DSH 输入框完成真实回复。验证已有会话目录、历史恢复、模型及权限选项、会话创建和改名。审批时切走再切回，待审批恢复；通过原有「允许一次」执行指定测试文件写入，结果及文件内容一致。原有「停止生成」中断真实回合，刷新后恢复历史，未再次发送。
- 复制出的发行 EXE 在真实 Tauri WebView2 中完成 Codex 回复，切换后桌面桥接可用。关闭窗口时 Codex 正在生成，独立后台继续运行，随后在普通浏览器读取同一会话，确认其完成。WebView 的离线再在线验证保留原页面和未发送草稿，没有重放发送。
- 实测修正 DSH 审批回复的 `args` 信封、中断回合的原生原因结构、首轮模型与权限目录更新，以及连接恢复时的会话发现时序。Windows 目录标识统一路径分隔符与大小写，新增目录解析实际路径。外部会话隐藏 DSH 专属反馈与分叉控件，避免向原生 DSH 会话存储发起错误操作。审核时移除了逐个 token 重发元数据和运行状态的重复消息。

测试业务与管理服务均已停止，本轮调试端口已释放，临时复制的 DSH 凭据和浏览器认证 Cookie 已清理。自动冒烟使用无个人凭据的隔离数据，真实模型调用的结论来自上述独立测试。

macOS、Linux 只检查了受影响的 Node 标准 API、命令发现和进程分支，本轮没有在这两个平台运行。图片和通用附件、归档、置顶、全文搜索及正式 TUI 消费留待后续任务，未计为本轮已验证能力。
