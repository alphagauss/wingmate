# 2026-11-10 后台设置完善

DSH 仍固定为 0.2.2-rc.1。本次在现有 Wingmate 后台服务插件中补充数据目录、登录启动和运行包待切换提示，并复用 DSH 控件和主题调整布局。

## 实现取舍

- 数据目录由 DSH 进程调用该版本的官方目录解析器取得。桌面只打开已验证后台报告的目录；旧后台缺少该字段时隐藏入口。
- 登录启动复用 `wingmate start`，平台差异留在桌面适配层。使用系统启动项，默认关闭，程序搬迁后可重新注册。平台和环境约定见[桌面程序](../../src-tauri/README.md)。
- 新桌面连接旧运行包时通过宿主桥接提示待切换，旧插件也能显示提示。切换继续使用已有的显式重启流程。
- 审核修正了 Windows 仅凭时间戳判断禁用状态的问题，以及 Linux 将其他配置段的字段误用于主启动项的问题。

## 验证

在 Windows x64 上完成 `pnpm test`、Rust 格式检查、JavaScript 语法检查和差异检查。Windows 启动项测试使用独立临时注册表键，覆盖注册、系统禁用标记、路径变化、重新注册和重复移除。

实现阶段已通过复制出来的单文件 EXE 冒烟，确认自定义 DSH 数据目录和释放后的插件可用。真实 WebView2 验证覆盖设置页、窄屏、明暗主题、旧运行包提示及确认重启后提示消失。本次审核后的状态解析修正通过相关回归测试，未重新执行注销登录。

macOS 和 Linux 只核对平台分支及依赖，并在 Windows 临时测试工程中编译、测试其启动文件生成和状态解析。未在对应系统上执行完整应用及真实登录验收。

## 已有安装

已有后台可继续工作。明确重启后加载新版插件及目录信息；登录启动需用户主动开启。
