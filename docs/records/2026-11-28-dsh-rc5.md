# 2026-11-28 DSH 0.2.2-rc.5 升级

桌面、无 GUI 和 Android 本地版共用的 npm 锁从 `0.2.2-rc.1` 升至 `0.2.2-rc.5`，随包插件与独立 demo 同步更新兼容版本。校验输入为官方 npm 发布包和上游标签 `dsh-v0.2.2-rc.5` 对应源码（提交 `9c2670d3`）。运行时顶层 Zod 跟随上游升至 `4.6.6`，继续复用一份安装。保留上游新增的版本对应源码和文档，供插件开发查阅。[版本对比](https://github.com/deepseek-ai/deepseek-harness/compare/dsh-v0.2.2-rc.1...dsh-v0.2.2-rc.5)

## 上游变化

- `rc.2` 增加 Git 工作树审阅、具名多层 SubAgent 和会话级 AgentTeam。会话归档默认清理符合条件的工作树，保留分支和提交。会话支持批量追加，日志格式沿用原版。[rc.2 发布说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.2)
- `rc.3` 增加实验性的 DeepSeek 对话导入插件。`rc.4` 改善模型异常响应处理，并修复官方桌面端 LiveShare 建立分享的问题。[rc.3 发布说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.3) · [rc.4 发布说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.4)
- `rc.5` 自动按模型路由选搜索提供方。DeepSeek 官方及账号路由默认使用服务端搜索，计入模型 token 费用，其他模型默认用 DeepSeek Search API。显式配置的搜索提供方优先。[搜索迁移指南](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.5/docs/upgrade-guide/v0.2.2-rc.4/web-search-deepseek-model-default/guide.zh.md)
- 创造模式将插件开发指南并入 `dsh-doc`。Wingmate 随包开发技能和 demo 模板都改用 `dsh-doc` 下的 `references/plugin-development.md`。[技能迁移指南](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.5/docs/upgrade-guide/v0.2.2-rc.1/dsh-doc-skill/guide.zh.md)

## 裁剪与版本补丁

`rc.2` 起，Web 组合用 `office-kit` 替代 `office-to-pdf`，内置 `skill-office`，由 `standard` 和 `ptc` 预设挂载技能激活的渲染、转换、重算工具。文档解析在 DSH 宿主内执行。实际 npm 依赖把 LibreOffice Kit 从 `0.1.5` 升至 `0.2.3`，引擎和 WASM 仍使用 `@deepseek-ai/libreoffice-kit*` 包名。[转换包迁移指南](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.5/docs/upgrade-guide/v0.2.2-alpha.3/office-kit-package/guide.zh.md) · [原生工具迁移指南](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.5/docs/upgrade-guide/v0.2.2-alpha.3/office-operation-tools/guide.zh.md)

沿用现有引擎裁剪规则，按新版组合禁用转换和内置技能，移除两个预设的 Office 工具并重定位侧栏预览补丁。预设补丁只移除对应条目，保留上游预设的其余设置。File Viewer 继续处理 Word、PowerPoint 等格式，Excel 保留 DSH 预览。独立安装 File Viewer 的配置只插入插件条目。适配及撤销条件见[文件预览模块](../../bundled-plugins/wingmate-file-viewer/README.md#与上游的适配)。

同步新增以下发行裁剪与配套补丁（保留所有包的许可证，并保留全部 `@deepseek-ai/*` TypeScript 源码与文档供离线创造模式查阅）：

- 补全 `.mts.map` / `.cts.map`（含 `.d.mts.map` / `.d.cts.map`）调试映射排除；排除 `node-pty/third_party` 冗余构建文件、`@mixmark-io/domino/{test,.yarn}` 测试与构建夹具，以及 `@deepseek-ai/*/src` 下已在同包 `lib/assets/` 打包的重复静态资源（`.webp`/`.png`/`.woff2`/`.svg` 等）。
- 裁剪默认关闭的 `@deepseek-ai/dsh-experimental-inspector`（内嵌 DevTools 前端），并从 `@deepseek-ai/dsh-experimental-inspector-profile` 的 `cordis.patch.yml` 移除该项，保留「会话数据诊断」与「统计」页签。
- 裁剪重复的 `@vscode/ripgrep*`，通过补丁让 `@deepseek-ai/dsh-util-ripgrep` 优先复用桌面 `toolchains/fallback/rg` 与 Android 来宾 `/usr/bin/rg`（未裁剪的开发态继续回退 `@vscode/ripgrep`）。

重新校验目录选择器和 Excel 延迟加载样式，保留横向滚动条回退。Android 离线回环调用适配新版编译产物，目录起点、凭据、共享存储和来宾 `rg` 补丁重新校验实际发布文件及顺序哈希。移除旧版 `dsh-0.2.2-rc.1.json` 补丁文件。

## 验证与已有安装

- `pnpm format:check` 和 `pnpm test` 通过。Rust 测试串行运行，避免与发行冒烟争用本机 Web 端口。
- Windows x64 单文件构建与发行冒烟通过（`wingmate.exe` 95.77 MiB），覆盖插件安装更新、网关长连接、运行目录复用、终端、图片及语音模块加载，以及新增的裁剪断言（内嵌 DevTools 已裁且开发者工具保留会话诊断与统计、重复 `@vscode/ripgrep` 已裁且 `dsh-util-ripgrep` 实际解析并执行随包 `rg`、DSH TypeScript 源码保留且 `src/` 重复静态资源已排除）。基础归档在补足上述裁剪后从 58.84 MiB 降至 48.35 MiB（低于 `rc.1` 的 49.35 MiB）。此前已用隔离 Edge Chromium 打开 DOCX、PPTX 和 XLSX 验证 File Viewer 与 DSH 表格预览。
- 补齐 `dsh-doc` 引用后，插件开发测试和 Windows 发行冒烟通过。核对了开发组件归档及单文件释放后的技能与 demo 指引。
- 19 条桌面 + Android 顺序补丁已在缓存安装树上校验通过；新增裁剪与 `rg` 补丁后尚未在 WSL 重新生成 Android ARM64 载荷，亦尚未在 Android 真机、Linux 或 macOS 上运行验收。未调用真实模型、未执行语音推理，也未在 `rc.5` 下做 Codex 外部后端的真实 Web 联调。

已有电脑端后台继续运行原版本，显式「重启并更新」后切换新组件。Android 本地版按既有载荷升级规则处理。Wingmate 无需迁移 DSH 会话或覆盖用户 Profile，使用自定义旧 Office 行或搜索提供方的配置可参照上游迁移指南。
