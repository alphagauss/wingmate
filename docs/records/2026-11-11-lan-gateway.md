# 2026-11-11 局域网网关与桌面双端

B2 将局域网监听、配对与后台恢复放在独立管理服务中。桌面使用本地标题栏和独立的远程 WebView，浏览器使用主机给出的同一个地址。使用入口见[桌面连接面板](../../apps/desktop/README.md)和[局域网分享](../../crates/wingmate-service/README.md#局域网分享)。

## 设计与适配

- 参考 deepseek-harness-desktop `fa55bd68883e` 的入站代理、DSH Cookie 换取、二维码和桌面主机切换。Wingmate 使用自己的 Rust 服务与 Tauri WebView 管理，参考目录未成为构建输入。
- DSH 的下载接口会返回相对跳转。网关按原请求地址解析并保持分享来源，已用发行包实际下载文件并比对字节。
- 二维码在桌面本地生成，使用 `qrcode` 的 SVG 输出。Tauri 的独立内容 WebView 使用当前锁定版本的多 WebView 接口，窗口命令按调用 WebView 及来源校验。共享启动页随管理服务提供，无 GUI 发行也可远程恢复。

## Windows x64 验证

- `pnpm test` 通过。服务测试覆盖配对过期、重复兑换、来源校验、转发与撤销长连接，管理测试覆盖业务实例校验和远程停机后启动。
- `pnpm build --headless`、`pnpm build` 和发行冒烟通过。复制出的无 GUI 单文件在隔离目录完成真实 DSH 会话创建、上传、下载字节比对、插件资源、WebSocket 握手和撤销后断开。业务停止后，原地址提供启动页及资源，可经同一会话启动新实例。
- 在同一台电脑使用两套独立管理目录、DSH 数据和 WebView2 资料。通过本机 WLAN 地址验证双向连接、标题栏切换、保存主机地址、显示二维码和返回本机。关闭被连接端桌面后，从另一端停止其业务，原连接自动回到启动页并成功恢复，发起端的本机实例保持原身份。
- 远程工作台切换到 Codex ACP 测试适配器后显示其独立会话，切回 DSH 后恢复原生工作台。真实模型调用的实测范围见 [A1 记录](2026-11-11-acp-backends.md)。

跨设备扫码、第二台实体设备的防火墙和网络可达性留待实测。macOS 和 Linux 本轮未运行。公网和 SSH 进入后续任务。
