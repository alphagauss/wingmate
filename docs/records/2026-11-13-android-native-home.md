# 2026-11-13 Android 原生首页与工作台桥接

在 Android 12 ARM64、WebView 96.0.4664.104 上对照旧版和并装的测试包。核对两版首页入口、原生控件、鲸标和标题居中、黑底搜索按钮，以及本机工作台排在首位。扫码页成功打开相机预览，切换手动地址后通过 USB 转发的测试网关验证身份检查、配对 Cookie 和最近连接记录。该测试未使用局域网广播或公网隧道。

本地测试包从空数据安装 ARM64 载荷并启动前台服务。在真实工作台 WebView 核对输入区和主题同步。通过 CDP 注入模拟会话状态，应用在后台发出系统通知，点按通知后回到工作台并打开对应会话。未调用真实模型，未用实体二维码完成识别。

两种 Release APK 均通过测试签名、16 KiB 对齐和包内容检查。两包均携带新工作台桥接，无旧首页资源和旧移植许可文件。远程包没有运行载荷和原生库，本地包包含 ARM64 载荷和 AGPLv3 声明。两种构建的配对解析、工作台桥接和 WebView 兼容测试均通过。本地运行时 JVM 测试有三个需要 POSIX 文件系统的用例在 Windows 跳过。
