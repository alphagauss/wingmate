# 2026-11-05：运行时体积优化记录

这是当时的实验与验证记录，不代表当前所有版本的平台支持、体积或测试覆盖。后续维护遵循 [运行时维护指南](../runtime-maintenance.md)。

## 输入与范围

Windows x64，Node 24.15.0，DSH npm 发布版 `0.2.2-rc.1`。目标是保留功能、插件开发所需内容和许可证，缩小单文件分发体积。

原始依赖树约 745.9 MiB。将 57 份 `zod@4.4.3` 合并为一份，兼容范围消费者由原顶层 `4.6.7` 改用 `4.4.3`；同时提升共享的 debug、ms。其余保留包的版本与 integrity 未变，338 个官方 `@deepseek-ai` 包的版本与 integrity 保持不变。

分发时排除 source map、PDB 和明确的异平台预编译文件，保留完整安装树、类型声明、TS 源码、许可证、Office、图片、语音及现有 WASM 内容。最终归档中普通文件 25,110 个，内容约 435.2 MiB。

## 同内容压缩对比

各格式压缩同一份 tar，解压后 SHA-256 一致。解压数值是三次热缓存解压并计算哈希的中位数，不包含落盘和 DSH 启动。XZ 使用 7-Zip，耗时包含其进程与管道开销；结果只代表本次环境与实现。

| 方案 | 运行包 MiB | 压缩秒数 | 纯解压秒数 |
| --- | ---: | ---: | ---: |
| 原始依赖树 + gzip 6（体积基线） | 186.1 | 未记录 | 未记录 |
| 去重裁剪 + gzip 6 | 135.8 | 8.7 | 1.85 |
| 去重裁剪 + gzip 9 | 135.3 | 18.6 | 1.78 |
| 去重裁剪 + Zstd 19 | 99.1 | 182.0 | 3.47 |
| 去重裁剪 + XZ 6（8 MiB 字典、单线程） | 92.8 | 96.3 | 3.65 |

选择 Zstd：比 XZ 多约 6.2 MiB，首次压缩也更慢，但可以复用 Node 构建环境，正常构建不增加 XZ/7-Zip 工具前提。Rust 解压库静态链接进成品，使用者无需另装 Zstd。

当时 Release EXE 从 203,714,048 字节（194.3 MiB）降至 112,715,776 字节（107.5 MiB），减少约 44.7%。这两个成品大小不是以后版本的验收阈值。

## 验证与适用范围

当时 5 项单元/归档测试、11 项单文件冒烟检查通过，覆盖 Web 认证、后台生命周期及身份拒绝、异常回收、Zod 与类型声明、Sharp 图片处理、node-pty 终端、语音原生库加载和 DOCX 转 PDF。未进行真实模型 API 调用、语音模型推理或其他平台验证。

本记录早于随后按 DSH 版本命名释放目录的调整，不应据此推导当前缓存复用策略；该策略以维护指南为准。

复测入口为 `pnpm runtime:prepare` 和 `pnpm runtime:benchmark`。比较命令需要 PATH 中的 `7z`，会生成新的 `work/compression-*` 结果。原始本机结果位于 `work/compression-qBH0ZL/result.json`，不纳入 Git，清理后可按当前依赖重新测量；新结果不能当作复现了历史版本。
