# 桌面前端

提供 Wingmate 自有的启动与连接体验。当前聊天和 Agent 交互使用官方 Web，不在本模块维护其副本。桌面设置、连接管理等后续界面按实际需求加入，不视为已经交付。

界面应说明后台是否可用、失败发生在哪个阶段，以及用户能采取什么操作。构建路径、内部管理凭据等实现信息不进入正常用户流程。

启动页按后台报告的实际阶段更新。只有发行版实际解压内嵌运行包时才显示解压状态。开发版在窗口打开前由终端准备运行时。等待时显示不定进度，失败时保留同一张状态卡，并将诊断信息放在可展开的详情中。

本模块不直接拥有或管理后台进程；与桌面宿主有关的操作和权限约定见 [桌面程序](../../src-tauri/README.md)。
