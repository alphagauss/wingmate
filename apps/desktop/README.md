# 桌面前端

提供 Wingmate 自有的连接面板，复用[共享启动页](../launcher/README.md)。聊天、Agent 交互和后台在线时的管理入口在 DSH Web 中。

Windows 标题栏右上角的电脑图标打开「远程连接」浮层，当前工作台留在原处。浮层跟随本机工作台的明暗主题，也可从本机启动页或后台服务设置打开。「连接主机」可粘贴分享链接或选择最近连接。远程工作台使用独立内容区，顶部显示当前地址和连接类型。点「返回本机」释放当前连接并回到原页面，服务端后台继续运行。

「分享本机」可开启局域网分享并生成配对链接与二维码。在「插件 → 内置插件配置 → Wingmate 后台服务」卡片中可指定本机 IPv4 地址、查看和撤销设备。

界面应说明后台是否可用、失败发生在哪个阶段，以及用户能采取什么操作。构建路径、内部管理凭据等实现信息不进入正常用户流程。

启动页按后台报告的实际阶段更新。只有发行版实际解压内嵌运行包时才显示解压状态。开发版在窗口打开前由终端准备运行时。等待时显示不定进度，失败时保留同一张状态卡，并将诊断信息放在可展开的详情中。

Windows 启动页使用与工作台相同的[窗口控件](../../src-tauri/README.md#windows-标题栏)，页面明暗随标题栏切换。

停止后台后回到首页，可再次启动。启动和连接失败时可在首页重试。遇到同版本旧运行包时，首页允许继续连接，或在确认会中断任务后重启以启用新内容。

本模块不直接拥有或管理后台进程；与桌面宿主有关的操作和权限约定见 [桌面程序](../../src-tauri/README.md)。
