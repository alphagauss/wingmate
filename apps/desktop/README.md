# 桌面前端

提供 Wingmate 自有的连接面板，复用[共享启动页](../launcher/README.md)。聊天、Agent 交互和后台在线时的管理入口在 DSH Web 中。

标题栏的「远程连接」入口在主窗口内打开浮层，当前工作台留在原处。浮层沿入口对齐，空间不足时向窗口内收，内容过长时在浮层内滚动。点击空白区域、按 Esc 或切换到其他窗口可关闭。各平台共用边框、圆角、阴影和开合动效，系统开启减少动态效果时即时开合。Windows 和 macOS 的浮层跟随本机工作台的明暗主题，Linux 默认跟随系统主题。

「连接主机」可粘贴连接地址或配对链接、选择最近连接或搜索局域网。搜索先探测已保存的局域网地址，再扫描当前网段的[网关端口](../../crates/wingmate-service/README.md#web-入口)，可以随时取消并使用已发现的结果。点选需要密码的主机后，密码框在该行下方展开。远程工作台使用独立内容区，顶部显示当前地址和连接类型。点「返回本机」释放当前连接并回到原页面，服务端后台继续运行。

「局域网」显示当前的本机和局域网入口，可在密码行设置、修改、停用或查看本机的分享密码。开启局域网访问后，配对卡片提供地址、二维码和完整链接。有多个地址时，点地址即可切换。「公网隧道」用于选择临时或具名模式、查看首次下载进度、启停隧道和生成公网配对链接。具名模式可选择有效期并撤销尚未使用的邀请，也显示 Cloudflare 应使用的实际回源地址。具名隧道配置和设备撤销见 [DSH 的 Wingmate 后台服务详情页](../../bundled-plugins/wingmate-web/README.md)。配对和连接规则见[服务模块](../../crates/wingmate-service/README.md#web-入口)。旧版浮层的最近连接在升级后首次打开浮层时导入桌面共用记录。

界面应说明后台是否可用、失败发生在哪个阶段，以及用户能采取什么操作。构建路径、内部管理凭据等实现信息不进入正常用户流程。

启动页按后台报告的实际阶段更新。检查、连接已有后台和打开工作台共用短暂的状态卡显示延迟，连接成功后立即跳转。解压、启动、停止以及需要用户处理的状态立即显示。只有发行版实际解压内嵌运行包时才显示解压状态。开发版在窗口打开前由终端准备运行时。等待时显示不定进度，失败时保留同一张状态卡，并将诊断信息放在可展开的详情中。

启动页使用与工作台相同的[窗口控件](../../src-tauri/README.md#桌面标题栏)。

停止后台后回到首页，可再次启动。启动和连接失败时可在首页重试。后台运行且有组件待更新时，可选择「继续使用」连接当前后台，或点「重启并更新」直接重启后台以启用新组件。重启会中断正在运行的任务。

本模块不直接拥有或管理后台进程；与桌面宿主有关的操作和权限约定见 [桌面程序](../../src-tauri/README.md)。
