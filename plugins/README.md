# 自用 DSH 插件

承载本项目维护的 DSH 插件。当前没有自用插件，也没有额外社区插件预装流程；本目录用于保留模块边界。

插件遵循所选 DSH 的插件与 Profile 机制，避免在 Wingmate 中另建一套业务插件协议。普通前端共享组件归 [packages](../packages/README.md)。

创建插件目录或加入工作区不代表它已进入发行包。实际集成时按 [运行时维护指南](../docs/runtime-maintenance.md#社区和自用插件集成)记录用途、来源、兼容性、启用方式、适配理由和验收范围；本项目维护的插件在自己的 README 中保存这些内容。
