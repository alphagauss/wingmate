# 分发运行时

负责交付随 Wingmate 携带的 DSH 运行内容。这里的发行依赖与前端开发依赖分开维护，精确版本以本目录的 [声明](package.json)和 [锁文件](package-lock.json) 为准。

本模块不管理用户会话、凭据或个人插件配置。安装树完整保留用于开发与组装，发行归档可以按已确定边界精简；本地参考源码不自动成为发行输入。

版本获取、打包范围、去重裁剪、压缩选择、释放目录复用、升级验收及社区插件集成统一遵循 [运行时维护指南](../docs/runtime-maintenance.md)，不在这里重复维护规则或测量结果。

Android 本地版的基础环境、载荷准备与构建来源见 [Android 本地运行载荷](android/README.md)。
